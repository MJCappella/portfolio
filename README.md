## 🏗️ Project Architecture & Modular Sections

The project uses a clean, componentized architecture:

- **Root [`index.html`](file:///c:/Users/mathunga/Documents/Projects/portfolio/portfolio/index.html)** is a concise, lightweight master layout (**only ~68 lines**) that loads each section dynamically via `data-include`.
- **[`sections/`](file:///c:/Users/mathunga/Documents/Projects/portfolio/portfolio/sections/)** contains the isolated, modular HTML components for each part of the website.
- **Optional Static Bundle**: Running `npm run build` generates a standalone, inlined production bundle in `dist/index.html` without touching the clean root `index.html`.

```text
portfolio/
├── index.html                 # Lightweight master layout (~68 lines)
├── dist/index.html            # Optional self-contained bundled file (generated by build)
├── build.js                   # Compiler script generating dist/index.html
├── package.json               # npm scripts (npm start, npm run build)
├── sections/                  # Modular logical HTML components
│   ├── header.html            # Hero banner & social channels
│   ├── navbar.html            # Sticky navigation bar
│   ├── about.html             # Bio & expertise breakdown
│   ├── resume.html            # Master tabbed resume container
│   ├── experience.html        # Redesigned professional experience timeline
│   ├── skills.html            # Redesigned domain skill clusters & chips
│   ├── education.html         # Redesigned university education & research
│   ├── stats.html             # Counter metrics (Years, Repos, Clients)
│   ├── services.html          # Full stack & AI engineering services
│   ├── portfolio.html         # Horizontal flowing project carousel
│   ├── contact.html           # Contact form & location-neutral channels
│   └── footer.html            # Copyright & credits
└── assets/
    ├── css/
    │   ├── michaeljames.css   # Main theme & horizontal carousel styles
    │   ├── resume.css         # Redesigned experience, education & skills styling
    │   └── sections-redesign.css # Redesigned hero, about, services, contact styles
    └── js/
        └── michaeljames.js    # Component loader, carousel & tab navigation
```

## ⚡ Development & Build Commands

### 1. Rebuild index.html from modular sections:
Whenever you modify any file in `sections/`, run:
```bash
npm run build
# OR directly:
node build.js
```

### 2. Preview locally:
```bash
npm start
# Opens a lightweight local HTTP server at http://localhost:8080
```
Or simply open `index.html` in your browser.
